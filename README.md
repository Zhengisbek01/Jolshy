# Jolshy

Мониторинг дорог для акимата: ИИ-детекция ям, разметки и знаков с камер транспорта, приложение инспектора с GPS, контроль подрядчиков и автоматические заявки в ЕКЦ 109.

Проект ТОО «JASA Ltd» для программы G-TON Astana Hub. Задачи: «Дороги», «Дороги области», «ИИ-мониторинг дорог».

## Запуск

```
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

Тестовая версия работает без сервера. Данные генерируются в браузере: 14 областных дорог (1 588 км), 25 улиц областного центра, 8 автобусов и 4 машины ДЭУ с камерами, около 870 дефектов за 60 дней. Всё сохраняется в localStorage; «Сбросить демо» возвращает исходное состояние. Нормативы устранения — демо-значения, настраиваются администратором.

## Как платформа закрывает задачи

| Задача | KPI акимата | Где в платформе |
| --- | --- | --- |
| Дороги: видеофиксация, заявка в 109, карта | 90% объектов с геопривязкой | Камеры → проверка ИИ → наряд подрядчику + заявка в 109; обращения 109 без адреса привязываются к карте кликом |
| Дороги области: приложение инспектора с GPS | Передача в работу за 5 минут, 95% в срок, 100% сети за месяц | Объезд с GPS-треком, фиксация в одно касание, автопередача по зоне подрядчика, приёмка с фото до/после, покрытие сети |
| ИИ-мониторинг с камер транспорта | Км под мониторингом, время от выявления до устранения | Камеры на автобусах и ДЭУ, автоподтверждение от 0,90, покрытие за 7 дней, медиана выявление → устранение |

## Структура кода

- `src/data/generate.js` — генератор демо-сети, транспорта, объездов и дефектов
- `src/lib/engine.js` — SLA, автопередача по зоне, покрытие, KPI, рейтинг подрядчиков
- `src/lib/geo.js` — геометрия сети, километраж, координаты
- `src/components/MapView.jsx` — карта сети (SVG, масштаб, слои покрытия)
- `src/components/Frame.jsx` — кадр с камеры с рамкой детекции (демо)
- `src/pages/*` — кабинеты ролей
